Code

Putting a rat head on a face

// src/lib/ratVision.ts
const FOREHEAD = 10
const CHIN = 152
const FACE_LEFT = 234
const FACE_RIGHT = 454
const HEAD_SCALE = 2.0

const faces = face.detect(canvas).faceLandmarks.map((lm) => {
  const top = lm[FOREHEAD], chin = lm[CHIN]
  const a = lm[FACE_LEFT], b = lm[FACE_RIGHT]
  const dx = (b.x - a.x) * W
  const dy = (b.y - a.y) * H
  return {
    x: ((top.x + chin.x) / 2) * 100,  // % of the photo
    y: ((top.y + chin.y) / 2) * 100,
    w: ((Math.hypot(dx, dy) * HEAD_SCALE) / W) * 100,
    rot: (Math.atan2(dy, dx) * 180) / Math.PI,
  }
})
  • Points 10 and 152 are the top of the forehead and the chin. Halfway between them is the face's center, where the rat's skull goes.
  • Points 234 and 454 are the edges of the face. Their distance sets the head's size.
  • Their angle tilts the rat head when a person tilts theirs.
  • Positions are percentages, so the overlay stays put as the photo resizes.

Testing

The first test run said NO RAT to everything

Every photo, including a clear portrait, came back with zero faces.

  • Claude Code re-ran detection in two browsers, two MediaPipe versions, on CPU and GPU. Still zero.
  • Then it looked at the test photos: an extreme close-up and a crowd in sunglasses.
  • The face detector is tuned for selfie-distance faces. Normal portraits found 1 and 3 faces right away.
Lesson

The code was fine; the test photos were bad. Running the real thing in a real browser caught it in minutes, instead of a visitor catching it after deploy.

Testing

The handoff's rat rule missed 2 of 3 rats

ImageNet has no "rat" label. Rats show up as beaver, mink, weasel, squirrel.

Old rule: one rodent label at 0.15 or more. Caught 1 of 3 rats.

New rule: add up every rodent label in the top 10; 0.08 or more is a rat. Caught 3 of 3, while the cat stays at 0.018.

Step 4 · Firebase

Shipping an update

# once per machine
pnpm add -g firebase-tools
firebase login
firebase use --add <project-id>

# every update
pnpm build
firebase deploy --only hosting

# optional
firebase hosting:channel:deploy preview  # test URL first
firebase hosting:rollback                # undo a bad release
  • Still the free Spark plan. No functions, no storage, no keys.
  • The models come from Google's CDN, so the deploy stays small.
  • Visitors download the models once, on their first upload.

Takeaways

What I'd tell the next person

Design first

A prototype beats a description

Claude Design produced something I could click, plus a handoff doc with exact copy, colors and checks. Claude Code had little to guess.

Test for real

Both bugs surfaced only in a real browser

The bad test photos and the too-strict rat rule were invisible in the code. Real photos found them in minutes.

Keep the calls

The rules that mattered were human

No uploads, a normal cursor, the notice copy, "a rodent is fine". AI did the legwork inside those lines.
